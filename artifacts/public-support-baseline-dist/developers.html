How Villow is built

  • React web app for browsers on phones, tablets and computers
  • Hosted on Vercel
  • Supabase for the database
  • YouTube Data API and YouTube's official embedded player
  • Google sign-in

Built on YouTube's public API, with no special access.

How Villow Setup works

Run your own private Villow or join one run by someone you trust. One person operates the hosting and database, and friends sign in. There's no central Villow everyone signs into.

Villow Setup is a computer app (Windows today; macOS and Linux: TBDmacOS and Linux availability) that walks you through creating the accounts Villow runs on, Vercel, Supabase and Google Cloud, then builds and connects everything. No GitHub, Git or terminal needed.

YouTube access uses a daily API quota from the owner's Google Cloud project, shared by everyone on that Villow. That's part of why each Villow is run by its owner for a small group.
