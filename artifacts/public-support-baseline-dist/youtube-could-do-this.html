YouTube could do this

We built this from the outside. YouTube could offer it directly.

Villow demonstrates that these controls are possible. YouTube could offer them directly to everyone. Fix the Web is asking for native choices over feeds, boundaries and reflection, informed by evidence about what helps.

YouTube has started. Here's what Villow adds.

YouTube already offers useful time-management tools. This compares specific controls, rather than claiming it has none. Availability and defaults can differ by device and account.

YouTube's documented controlsAdditional choices in Villow
Take a break reminders pause playback until dismissed or resumedEnforced break intervals in Villow, alongside daily limits and schedules
Bedtime reminders can interrupt or wait for the video to end, and can be dismissed or snoozedA bedtime window with stop-for-tonight, 30-minute snooze or dismiss-for-tonight choices, alongside per-day schedules
Shorts feed limits include zero, with an option to dismiss or ignore the limitChosen limits on time, opens and individual channels in Villow; the extension adds ceilings on recommendations seen and browser usage
Subscriptions show recent uploads from channels you followTitle filters, duration ranges, channel check-in cadence and a maximum feed size with an end
Recommendation feedback includes Not interested and Don't recommend channelA daily recommendation-exposure ceiling on YouTube through the extension, plus optional discovery sources in Villow
Time watched summarizes viewing from watch history, with documented exclusionsChannel and source breakdowns, optional worthwhile ratings, a 30-day review and explained setting suggestions

Checked against the linked official YouTube Help pages on 12 October 2026. Villow coverage is its own usage plus YouTube in connected extension browsers; native YouTube apps and unconnected browsers are excluded.

Where the public API stops

  • Personalized recommendations and watch history aren't available to import through the Data API. Villow builds its own finite feed and measures activity within its coverage. You can still explore recommendations on YouTube through the extension.
  • Embedded playback has constraints. Villow doesn't provide background playback or change YouTube's official player functionality.
  • API access has quotas. Your installation shares its Google Cloud project's allowance.
  • Native creator controls would need YouTube support. An independent creator-submission service is also conceivable, but isn't implemented.

The YouTube Data API reference and developer policies describe the API and its constraints. Native platform support could make these choices easier to reach.

Shared reference points, room for different interests

Country charts can give people some common things to discuss beyond individualized recommendations. That consistency is part of the vision. Popularity still doesn't establish quality or truth, and we aren't claiming Villow has demonstrated reduced polarization.

Imagine these choices built into the platforms you use.

Fix the Web is asking for control over feeds and boundaries, access for independent research, and working prototypes that let people test different designs.

Villow is one such prototype. Optional feedback can help improve it and test its intentions. Private viewing data isn't automatically submitted to Fix the Web.
